# Проверка версии 1.3.0 — 17.11.2026

Пройдены проверки node checks.cjs и синтаксиса JavaScript. Проверены пределы стенки для шести диаметров, неизвестный диаметр, превышение стенки, отсутствие переноса листового режима, режим только корня, выбор присадки и наличие сведений для 53 марок. Регрессионные проверки геометрии, расхода, сохранения и ресурсов офлайн-кэша также прошли.

Браузерная проверка 1.3.0 выполнена в Chrome 17.11.2026. Проверено:
- Ø57×6, 09Г2С: автоматический ток корня/заполнения 85 А; предел стенки 13 мм; присадка Св-08Г2С; электрод WL15 Ø1,6 мм.
- Ø108×6: автоматический ток отсутствует; Ø108×12: только корень 100 А, заполнение не назначено. Попытка генерации полного TIG-плана заблокирована сообщением.
- Ø57×6: генерация пяти проходов по 179,070781 мм и 85 А; перенос метража 0,179070781 м; расчёт газа 119 л с заданными в тестовом проекте скоростью 100 мм/мин, газом 11 л/мин и продувками. Это тест арифметики, не рекомендация режима.
- АЛ9: СвАК5; Д16 и медь: без однозначного автоматического назначения; ручной выбор кандидата БрКМц3-1 работает.
- Ручное изменение тока переводит блок в ручной режим. После перезагрузки параметры сохраняются.
- Сервер предпросмотра остановлен; отдельный HTTP-запрос подтвердил отказ соединения. Страница повторно загрузилась из кэша, пересчитала толщину 3/6 мм, сохранила её после повторной перезагрузки. Справочник и вкладка установки доступны.
- В просмотренных сообщениях консоли ошибок приложения не выявлено; присутствовали ошибки служебного расширения браузера, не приложения.

Ограничения: не проверены реальные iOS/Android, системная установка, импорт/экспорт JSON, печать, мобильные размеры экрана и полный перебор всех сочетаний. Остановка сервера подтверждает автономность от сервера приложения, но не имитирует все особенности авиарежима телефона. Ниже — история предыдущих проверок.

# Проверка версии 1.0.0
17 ноября 2026.

Пройдены автоматические проверки checks.cjs: границы исходных данных, 53 марки, отсутствие экстраполяции, интерполяция, геометрия, пределы электрода и импульса/горелки, планы для диапазона 0,5–100 мм, расход и блокировка устаревшего плана, наличие ресурсов офлайн-кэша.

Проверено в настольном Chrome:
- загрузка и достижение «Офлайн готов ✓»;
- перенос табличного ориентира для стали 6 мм;
- ввод скорости 100 мм/мин;
- формирование шести редактируемых проходов;
- остановка локального сервера и повторная загрузка страницы из кэша;
- сохранение проекта после перезагрузки;
- переход к расходу без сервера: 60 минут дуги, 739 л газа с запасом для проверочного примера.

После проверки браузера добавлен запрет геометрической генерации для ИН без присадки; автоматические тесты повторно пройдены. Браузерный сценарий относится к ИНп и не затронут.

Установка на физических iPhone и Android, выгрузка приложения ОС, очистка данных системой, экспорт/импорт через мобильный файловый менеджер и печать на реальных устройствах в этой среде не проверены. Соответствие конкретной производственной технологии и полная нормативная верификация всех сочетаний не подтверждены.

Полная размерная верификация всех типов, графическое обозначение по ГОСТ 2.312 и автоматический выбор аттестованных технологических карт не реализованы. Встроенных подтверждённых карт нет. Это ограничение явно показано в приложении. Проверка на физических iOS/Android по-прежнему не выполнена.

## Версия 1.2.0 — 17.11.2026
Пройдены checks.cjs: предварительный расчёт круглой трубы, сохранение ручного тока, автоматическая присадка для имеющихся записей, отсутствие автоматического тока за диапазоном таблиц, миграция старых проектов в ручные режимы, запрет старой произвольной площади.
В Chrome проверено: круглая труба Ø108×6, автоматические геометрия/токи/присадка (Св-08Г2С), ручная смена корневого тока на 90 А, создание пяти проходов с длиной 339,292 мм каждый, обновление service worker с сохранением проекта. После остановки локального сервера страница перезагрузилась из кэша; пять проходов и ток 90 А сохранились. Последняя сборка кэша: tig-1.2.0-r2.
Тест подтверждает программную работу, а не пригодность сварочной технологии. Физические iOS/Android в этой среде не проверены. Для трубы применяется явно подписанный ориентир плоского стыка, а не подтверждённый трубный режим. Автоматические настройки горелки и циклограммы — стартовые значения, не универсально проверенная технология.
