# Проверка версии 1.0.0
17 ноября 2026.

Пройдены автоматические проверки checks.cjs: границы исходных данных, 53 марки, отсутствие экстраполяции, интерполяция, геометрия, пределы электрода и импульса/горелки, планы для диапазона 0,5–100 мм, расход и блокировка устаревшего плана, наличие ресурсов офлайн-кэша.

Проверено в настольном Chrome:
- загрузка и достижение «Офлайн готов ✓»;
- перенос табличного ориентира для стали 6 мм;
- ввод скорости 100 мм/мин;
- формирование шести редактируемых проходов;
- остановка локального сервера и повторная загрузка страницы из кэша;
- сохранение проекта после перезагрузки;
- переход к расходу без сервера: 60 минут дуги, 739 л газа с запасом для проверочного примера.

После проверки браузера добавлен запрет геометрической генерации для ИН без присадки; автоматические тесты повторно пройдены. Браузерный сценарий относится к ИНп и не затронут.

Установка на физических iPhone и Android, выгрузка приложения ОС, очистка данных системой, экспорт/импорт через мобильный файловый менеджер и печать на реальных устройствах в этой среде не проверены. Соответствие конкретной производственной технологии и полная нормативная верификация всех сочетаний не подтверждены.

## Версия 1.1.2 — 17.11.2026
Проверены 77 уникальных записей каталога, фильтрация ИН/ИНп/ЗН, границы толщин и диаметров, исключение неподходящих материалов, размеры ответвлений. Проверены миграция проекта версии 1.0, рекомендации электрода, изменение диаметра при росте тока, отсутствие выдуманной интерполяции в разрыве таблицы Miller, ограничение AC по EN=75%.

В Chrome проверены:
- обновление из прежнего service worker до версии 1.1.2;
- сохранение исходного проекта при обновлении;
- лист, ИНп, скос двух кромок, одностороннее выполнение: С17 при 6 мм;
- стальной трубопровод 108×12 мм: С17, процесс ЗН;
- изменение заданного тока с 140 до 600 А: рекомендация ЭВЛ меняется с 4 до 5 мм по историческим таблицам;
- применение рекомендации по кнопке;
- полная остановка sites-preview, перезагрузка из кэша и доступность обоих новых блоков.

Полная размерная верификация всех типов, графическое обозначение по ГОСТ 2.312 и автоматический выбор аттестованных технологических карт не реализованы. Встроенных подтверждённых карт нет. Это ограничение явно показано в приложении. Проверка на физических iOS/Android по-прежнему не выполнена.
