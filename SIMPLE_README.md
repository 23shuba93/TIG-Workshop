# TIG Сварка 2.0 — 18.11.2026

Основной сценарий: параметры → соединение / шов → результат. Никаких обязательных паспортов, подтверждений сторон шва и ручной сборки карты для получения предварительного результата.

Исследование rd-svarka-3.0.apk выполнено статически: прочитаны ресурсы интерфейса и перечень каталогов. APK не запускался, его платный доступ и активация не изменялись. Перенесён принцип экранов, а не исходный код, оформление или нормативы расхода электродов РД. Это PWA для двух платформ, не Android APK.

В результате доступны ток корня / заполнения, рекомендуемый вольфрам, кандидат присадки, газ, предварительный тип ГОСТ, оценка проходов и расхода. Старый полный интерфейс сохранён в expert.html; его проекты остаются в прежнем хранилище. Новый экран хранит собственные параметры отдельно.

## Что является оценкой
- Общая таблица Lincoln для стали/нержавейки: 0,6–4,8 мм. Между строками линейная интерполяция. Для 0,5 мм используется ближайший ориентир 0,6 мм.
- Свыше 4,8 мм для обычных сталей применена модель многопроходной сварки: корень по 1,5 мм, заполнение по 4,8 мм. Это допущение приложения, не назначенный изготовителем режим для толщин до 100 мм.
- Общий ориентир по толщине не содержит поправок на положение, тепловой сток трубы и тип соединения. Поэтому это стартовый диапазон для проб, не утверждённая технологическая карта.
- Для цветных металлов используются справочные аналоги Юхина в пределах таблиц. Для специальных марок и отсутствующих диапазонов ток не придумывается; геометрия и расход остаются доступны.
- Автоматический выбор ГОСТ ограничен простыми разделками из подключённого каталога. Принятые зазор, угол и притупление НЕ заявлены размерами выбранного ГОСТ. Неизвестный тип не получает выдуманный номер.
- Расход — по принятому сечению, числу проходов, скорости 100 мм/мин (можно изменить), продувке 11 с и запасу газа 10%. Поддув и сборка не включены. Износ вольфрама без нормы не рассчитывается.

## Обновление
Распакуйте архив. Загрузите ВСЕ файлы из него в корень своего репозитория GitHub с заменой. Особо важны новые easy.js, easy-engine.js, easy.css, expert.html и обновлённые index.html, offline.js, sw.js. Откройте сайт с интернетом, нажмите «Применить» при предложении обновления, дождитесь «Офлайн готов». Затем можно работать без сети.

## Проверка
node checks.cjs — проверки прежнего расчётного ядра.
node easy-checks.cjs — новый сценарий для четырёх форм, масштабирование расхода, невозможная геометрия, специальные сплавы, свой электрод, предел числа проходов.
