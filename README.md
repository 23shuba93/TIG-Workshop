# TIG · Мастерская — одна PWA для Android и iOS
Версия 1.3.0, 17.11.2026. Рабочий автономный справочник и инженерный черновик расчёта, без регистрации и внешних библиотек.

## Установка на GitHub Pages — пошагово
1. Распакуйте ZIP. Создайте отдельный репозиторий, например TIG-workshop, чтобы сохранить прежний тренажёр.
2. В репозитории нажмите Add file → Upload files.
3. Загрузите ФАЙЛЫ ИЗ распакованной папки прямо в корень репозитория. Рядом должны лежать index.html, app.js, data.js, catalog.js, evidence.js, engine.js, auto.js, offline.js, sw.js, style.css, manifest.webmanifest и все четыре PNG. Дополнительные папки создавать не нужно.
4. Нажмите Commit changes. Если предлагается выбор, выберите Commit directly to the main branch; текст сообщения можно оставить предложенный. Подтвердите Commit changes.
5. Откройте Settings → Pages → Build and deployment → Deploy from a branch. Branch: main; Folder: / (root). Save.
6. Дождитесь успешной публикации. Откройте адрес, который показывает GitHub Pages. Не открывайте index.html из файлового менеджера: service worker требует HTTPS или localhost.
7. Дождитесь «Офлайн готов ✓». При проблеме приложение покажет отсутствующий файл. Сверьте его имя и регистр букв с архивом.
8. Android / Chrome: меню ⋮ → Установить приложение / Добавить на главный экран; либо кнопка установки в приложении, когда браузер её разрешит.
9. iPhone / Safari: Поделиться → На экран «Домой» → Добавить. Откройте значок, дождитесь готовности кэша.
10. Включите авиарежим и проверьте открытие. Повторное подключение нужно только для обновления приложения и открытия внешних источников.

Первичная загрузка небольшая. Статус имеет тайм-ауты и диагностику, а не бесконечное ожидание. Это кэширование service worker при посещении, а не постоянно работающий фоновый процесс: iOS/Android могут остановить приложение и удалить данные при нехватке места. Делайте резервные копии JSON.

## Порядок работы
1. «Расчёт»: материал, марка, заготовка, толщина, разделка, положение, газ.
2. Выберите подходящую таблицу Юхина и нажмите «Взять ориентиры таблицы». При несовпадении области применения перенос блокируется. Остальные режимы вводятся по вашей технологической карте.
3. Укажите скорость, присадку, охлаждение и паспортные ограничения. Для своего вольфрама выберите марку, диаметр и паспортный диапазон. Проверки обновляются сразу; кнопка ограничения тока предлагает значение в пределах электрода, но не гарантирует проплавления.
4. «Проходы»: сформируйте геометрический черновик или добавьте проходы вручную. Для каждого редактируются ток, напряжение, скорость, расход газа, длина, присадка, слой и зажигания.
5. После изменения основных исходных данных карта помечается устаревшей. Проверьте её перед расчётом расхода.
6. «Расход»: перенесите длину, задайте количество, поддув и параметры баллона. Износ вольфрама вводится по вашей норме; для Al есть отдельная историческая таблица в её диапазоне.
7. JSON сохраняет весь проект и переносится между телефонами. Печать позволяет сохранить карту PDF средствами браузера.

## Что реализовано
- 53 марки, семь групп материалов, четыре вида заготовки.
- Толщина 0,5–100 мм, точный ввод, ползунок, пресеты, периметры и проверки геометрии.
- Десять ограниченных табличных профилей Юхина, интерполяция внутри диапазона.
- Собственный электрод, паспортные пределы, геометрия заточки, проверки токов и импульса.
- Редактируемые проходы/слои, энергия дуги, расход газа/присадки, оценка баллонов.
- Справочник, источники, локальное сохранение, экспорт/импорт, печать.
- Общий для обеих платформ manifest и service worker, все рабочие ресурсы локальные.

## Границы готовности — прочитать перед применением
Это НЕ полностью автоматический подбор аттестованной технологии для всех 53 марок и всех толщин до 100 мм.
- Выбор марки в списке не означает наличие подтверждённого режима для неё. Многие значения требуют технологической карты.
- Добавлен автоматический отбор типов из таблиц 1 ГОСТ 14771-76 и ГОСТ 16037-80: каталог 77 типов. Для каждого проверяются применимые диапазоны ИН/ИНп или ЗН. При нескольких кандидатах уточните подготовку и подкладку. Это не полная проверка размерных таблиц и не формирование полного графического обозначения по ГОСТ 2.312. Для цветных металлов эти два стандарта не применяются.
- Исторические пределы электродов и режимы пособия не заменяют паспорт оборудования. Отечественные марки и ISO не считаются безусловными эквивалентами.
- Диаметры электродов и число проходов непрерывно не интерполируются. Глубокие разделки до 100 мм рассчитываются геометрически; режимы вне таблиц не экстраполируются.
- Число проходов генератора — оценка по высоте слоя и площади валика, может отличаться от исходной таблицы. Отдельные токи корня/заполнения не выдумываются там, где источник даёт только общий ток.
- Для ИН без присадки проходы добавляются вручную; модель заполнения присадкой к нему не применяется.
- Автоматические коэффициенты тока по газу/положению, универсальный подогрев и универсальные марки присадки не назначаются без подтверждённой технологии.
- Ar+O₂ заблокирован для обычного TIG. N₂ требует специальной технологии; часть данных Юхина относится к угольному электроду.
- Химическая очистка описана справочно. Полные производственные рецептуры травления и режимы опасных кислот не восстановлены по неполным данным.
- Обозначения положений и титановая цветовая шкала имеют пояснения; цвет сам по себе не подтверждает качество.
- Приложение не выдаёт аттестацию НАКС и не заменяет технологическую карту производства.

## Исходники и проверка
Сборщик не нужен. Файлы редактируются напрямую. checks.cjs — тесты расчётного ядра, запуск: node checks.cjs.
Для локального просмотра нужен HTTP-сервер. Для обновления измените версию кэша в sw.js, загрузите все изменённые файлы и используйте проверку обновлений в приложении.
Полные книги в архив не включены. Табличные выдержки привязаны к страницам пользовательского пособия Юхина; ссылки на первичные источники находятся в data.js и разделе «Справочник».

## Новое в версии 1.1.2
- Рекомендуемый электрод показан перед разделом ручного выбора. Указаны марка, цвет, диаметр при наличии данных, ток и источник. Кнопка применения сохраняет рабочие токи; карта требует сверки.
- Учитываются токи корня, заполнения, пика и актуальных проходов. Диаметр не интерполируется. Для AC-инвертора предлагается WL15; численная таблица ограничена Ar/Al/EN=75%. При других условиях нужен паспорт.
- Изменение диаметра, марки, полярности, газа или типа источника очищает старый паспортный диапазон.
- Каталог 45 типов ГОСТ 14771 + 32 типа ГОСТ 16037 включает и записи, не имеющие диапазона для выбранного способа: они показываются среди исключённых, не выдаются за подходящие TIG.
- Для врезок выберите «Угловое», круглый элемент, флажок стального трубопровода и соответствующий узел. Размеры ответвления вводятся отдельно.
- При одном совпадении предварительный код показывается автоматически. При нескольких вариантах выберите схему. Расчётная форма для расхода и подготовка для ГОСТ независимы: согласуйте их по чертежу.
- Все таблицы отбора работают офлайн. Ссылки на полные стандарты требуют интернета.
- Аттестованные карты не подключены. Для наполнения нужны утверждённая технологическая карта, документ об аттестации / готовности организации с приложениями и областью применения. Необходимы также сведения о материалах, оборудовании, присадке и условиях применения. Справочные таблицы автоматически не получают статус аттестованных.

### Обновление существующего приложения
Сначала экспортируйте проект JSON. Замените файлы в корне прежнего репозитория калькулятора, добавив catalog.js и auto.js. Дождитесь публикации GitHub Pages, откройте приложение с интернетом, затем нажмите «Применить» в сообщении об обновлении. Если сообщение ещё не появилось, закройте и снова откройте приложение. Проекты версии 1.0 читаются автоматически; карты сохраняются, но после изменения контекста требуется их сверка.


## Новое в версии 1.2.0
- Переключатели «Автоматически / Вручную» для процесса, геометрии, токов и газа, присадки, электрода, горелки, циклограммы, проходов и метража/плотности. Исходный материал, размеры и паспорт оборудования задаёт пользователь.
- Ручное изменение управляемого параметра переводит соответствующий блок в ручной режим. Старые проекты открываются в ручных режимах, чтобы сохранить введённые значения.
- Подробности электрода, горелки и циклограммы сворачиваются в автоматическом режиме. Фильтры ГОСТ и длинный список соединений убраны в раскрываемые панели; добавлен компактный выбор соединения.
- Для круглой трубы доступен предварительный ориентир из таблицы плоского стыка. Периметр и длины проходов рассчитываются по трубе. Поправки режима по диаметру и пространственному положению не подтверждены; подсказка об этом сохраняется в карте. Вне диапазона таблиц автоматический ток не назначается.
- Автоматическая присадка: первый кандидат из имеющейся записи пособия по марке металла; альтернативы показаны рядом. Отсутствующие записи не заменяются догадкой. Условия эксплуатации требуют проверки.
- Удалено поле «Площадь своей разделки». Проекты со старой произвольной геометрией требуют выбора расчётной формы перед созданием плана.
- Автоматические значения горелки и циклограммы пока являются начальными настройками проекта, а не проверенным подбором для всех сочетаний. Температуры подогрева и межслойная температура остаются по технологической карте. Автоплан проходов — геометрическая оценка.

Для обновления замените все файлы из ZIP в корне репозитория приложения. Не загружайте ZIP целиком как единственный файл сайта. Перед обновлением экспортируйте JSON, после публикации откройте «Установка» и примените обновление. Файл auto.js обязателен для запуска и подготовки офлайн.


## Изменения 1.3.0 — трубы и присадка
- Новые записи evidence.js дополняют сведения по присадке для всех 53 марок. Марочные рекомендации, групповые кандидаты и случаи специальной технологии различаются. Для условных вариантов автоматический выбор отключён.
- Стенка круглой трубы ограничена максимумом для наружного диаметра из таблицы 1 ГОСТ 8732-2025. Примеры D/Smax, мм: 25/8, 57/13, 108/28, 219/50, 325/75, 530/75. Это не проверка наличия каждой промежуточной пары размеров и не проверка прочности под давлением.
- Для другого сортамента, нержавеющих и цветных труб выберите «Другой стандарт / паспорт изделия», укажите документ и предел стенки для своего диаметра. Старые проекты круглых труб требуют такого уточнения.
- Режимы РТМ-1с §8.1 подключены в ограниченной области реализации D≤100, S=1–10 мм, неповоротный односторонний стык сталей, Ar, DC-, присадка. Для S≥10 вне этого профиля §8.2 задаёт только корень комбинированного шва. Полный TIG-план по одному режиму корня не создаётся.
- Для трубы больше не используется режим листа. За пределами подтверждённой области требуется ручная карта. Размеры разделки, расход газа, скорость, подогрев и свойства соединения проверяются отдельно.
- Ссылки и области применения источников сохранены внутри evidence.js и отображаются у рекомендаций. Исторические справочники не выдаются за действующие обязательные нормы. Аттестованные карты не подключены.
